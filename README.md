# SOC Journey

Catatan perjalanan belajar menuju Junior SOC Analyst, dari dasar komputer hingga investigasi endpoint dan event logs.

## Format harian

Setiap folder Day berisi empat file:

| File | Isi |
| --- | --- |
| `commands.md` | Commands, fungsi, dan contoh penggunaan |
| `materi.md` | Konsep, panduan praktik, dan skenario latihan |
| `evaluasi.md` | Hasil praktik, jawaban, penilaian, koreksi, dan hal yang perlu diperkuat |
| `milestone.md` | Catatan penting yang dipelajari pada hari tersebut |

Milestone mencatat pembelajaran, bukan klaim bahwa semua konsep sudah dikuasai. Hari tanpa hasil evaluasi diberi keterangan belum tersedia. Status dan nilai evaluasi lama tetap mengikuti catatan aslinya.
