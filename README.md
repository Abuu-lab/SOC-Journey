# SOC Journey

Catatan perjalanan belajar menuju Junior SOC Analyst, dari dasar komputer hingga investigasi endpoint dan event logs.

## Format harian

Setiap folder Day berisi empat file:

| File | Isi |
| --- | --- |
| `commands.md` | Commands, fungsi, dan contoh penggunaan |
| `materi.md` | Konsep, panduan praktik, dan skenario latihan |
| `evaluasi.md` | Hasil praktik, jawaban, penilaian, koreksi, dan hal yang perlu diperkuat |
| `milestone.md` | Catatan penting yang dipelajari pada hari tersebut |

Milestone mencatat pembelajaran, bukan klaim bahwa semua konsep sudah dikuasai. Hari tanpa hasil evaluasi diberi keterangan belum tersedia. Status dan nilai evaluasi lama tetap mengikuti catatan aslinya.

## Membaca bukti pembelajaran

Evaluasi mengelompokkan challenge, mini-project/investigasi, active recall, dan penilaian/hasil praktik. Jawaban dan koreksi yang tercatat dipertahankan; sebagian hanya tersedia sebagai ringkasan mentor. Soal yang diberikan tidak otomatis dianggap telah diselesaikan. Skenario latihan bukan incident terverifikasi pada endpoint aktual.

Evaluasi Day-05 dan Day-11 belum tersedia. Status Developing Day-03 dan Day-04 dipertahankan sebagai penilaian historis. Milestone mencatat konsep yang dipelajari/dilatih, bukan penguasaan otomatis atau sertifikasi kemampuan profesional.
