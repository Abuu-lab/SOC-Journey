Misalnya SOC menemukan:


```text

    ↓

    ↓

```

Kita mulai bertanya:

Kemudian kita menemukan:

```text
firefox.exe
    ↓
unknown.exe
```

Ini belum otomatis malicious.

Tetapi menjadi **suspicious context** yang perlu diperiksa.

# 3. PROCESS TREE

**Process Tree** adalah hubungan antara process dan parent process.

Contoh:

```text
services.exe
      ↓
svchost.exe
      ↓
child process
```

Atau:

```text
explorer.exe
      ↓
powershell.exe
      ↓
something.exe
```

Kita dapat membaca:

```text
Parent
  ↓
Child
```

Contoh:

```text
PID 5000
explorer.exe

PID 5500
powershell.exe
PPID 5000
```

Maka:

```text
explorer.exe PID 5000
        ↓
powershell.exe PID 5500
```

Karena:

```text
powershell.exe PPID = 5000
```

---

# 4. COMMAND LINE

Salah satu evidence penting dalam process investigation adalah:

> **Command Line**

Misalnya process:

```text
powershell.exe
```

Nama process saja belum banyak memberi informasi.

Tetapi:

```text
powershell.exe -ExecutionPolicy Bypass -File C:\Temp\update.ps1
```

memberikan jauh lebih banyak context.

Kita bisa melihat:

* executable
* arguments
* script/file yang dipanggil
* parameter
* lokasi file
* action yang diminta

Karena itu:

> **Process Name ≠ Full Context**

---

# 5. COMMAND LINE ≠ EXECUTABLE PATH

Ini harus jelas.

Misalnya:

```text
ExecutablePath:
C:\Windows\System32\cmd.exe
```

Sedangkan:

```text
CommandLine:
cmd.exe /c whoami
```

### ExecutablePath

Menjawab:

> **File executable-nya berada di mana?**

### CommandLine

Menjawab:

> **Process tersebut dijalankan dengan command/arguments apa?**

Kita belum boleh mengatakan:

Kita hanya mengatakan:

> **The process has suspicious characteristics and requires further investigation.**



# 15. ATTACK METHOD & DEFENSE — DAY 7

Sekarang sedikit pengenalan SOC terhadap attack technique.

Attackers dapat menggunakan **PowerShell** untuk menjalankan command atau script pada Windows.

Contoh sederhana:

```text
powershell.exe
       ↓
script.ps1
       ↓
action
```

Karena PowerShell merupakan legitimate Windows tool, keberadaannya sendiri **bukan bukti malware**.

Yang perlu diperiksa adalah **context**:

```text
Parent Process
CommandLine
User
Script Path
File
Network
Event Logs
```

### Defense

SOC dapat memonitor:

* PowerShell process creation
* Command Line
* Parent Process
* Script execution
* Windows Event Logs
* Endpoint telemetry

Jadi prinsipnya:

> **Living-off-the-land / legitimate tools can be abused, so context matters.**

Kita belum perlu masuk terlalu dalam ke PowerShell attack technique sekarang. Hari ini fokusnya tetap **process investigation**.
