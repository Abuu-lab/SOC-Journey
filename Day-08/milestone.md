# Day 08 — Milestone Hari Itu

- Mengambil current user dan group membership dengan whoami/whoami /groups.
- Mengidentifikasi user yang menjalankan process dengan Get-Process -IncludeUserName.
- Menggabungkan User, PID, PPID, ExecutablePath, dan CommandLine.
- Membedakan user account, process, identifier, dan privilege.
- High privilege atau user yang dikenal tidak otomatis membuktikan benign/malicious.
